## Layout

- `protocol/`: preregistration, frozen dataset, requests, run matrix, ablations, and fault scenarios.
- `annotations/`: three-state annotation guide and empty import templates.
- `results/`: append-only trajectory index plus derived CSV/JSON/figures after execution.
- `cost/`: append-only cost ledger. It must never exceed the preregistered category or total caps.
- `pilot/`: rejected preflight traces, official baseline grader output, checksums, and the disclosed protocol deviation.
- `preflight/`: machine-readable readiness state, pinned model metadata, and provider probe receipts; blocked snapshots are not passing receipts.
- `paper/`: ACM-style English paper source, bibliography, appendix, and build scripts.
- `reports/`: Chinese research report generated from the same frozen results.

## Commands

Run from `packages/autodrive-eval`:

```bash
bun test
bun typecheck
bun run validate
bun run plan
bun run boundary:plan
bun run pilot:plan
bun run analyze
```

Paid execution is fail-closed. It requires `run-eval --execute --executor <host-executor> --preflight <receipt> --artifact-root <root>` plus either explicit `--run-id` values or `--all`. The executor runs on the host, receives a per-run maximum cost, and must keep provider credentials outside the task container. Exit code 75 is the only retryable infrastructure failure, and it is retried once.

Before any paid call, validate the host-executor envelope with `verify-executor`. This mode strips provider credentials from the child environment, forces a zero-dollar pilot context, confines files to `dry-run/`, and never appends an experiment result. A paid `canary` requires a sealed canary preflight, exactly one primary-model run ID, and stores historical mechanism evidence under `canary/`. The separate `pilot` command executes only the frozen non-primary SWE-bench Verified task and writes a copied protocol, trajectory, ledger, and receipt under `pilot/`; neither command can append the formal result index.

The 2026-08-30 r4 through r7 pilot attempts all failed before provider admission. r4 exposed a missing `.gitignore` on a read-only `OPENCODE_CONFIG_DIR`; r5 exposed stale gzip metadata after Bun decoded a relayed response; r6 exposed a V2 Location startup race before the configured provider was committed; and r7 showed that the executor's V1 `options.apiKey` was not projected into the V2 runner credential field. All four attempts retained unchanged gateway spend and activity and produced no provider request artifact. Commits `55cc676f72`, `5efa37aa89`, `6f141c3e00`, and `8e4359a39a` cover the four defects.

The prospectively authorized r8 attempt crossed those gates and exercised the real worker/controller path: 18 worker and three controller requests produced three boundaries and durable decisions `continue`, `continue`, then timeout-safe `defer`; both automatic continuation inputs were admitted and promoted exactly once. The first-boundary grader passed all five P2P tests but failed the single F2P test. Final grading stopped before tests because the model patch and frozen test patch both modified `test_requests.py`, so neither forward nor reverse applicability check passed. The fail-closed run is an excluded charged evaluation failure, not an accepted pilot or ablation trajectory. Twenty responses have complete local usage totaling 123,052 prompt and 4,856 completion tokens; the final controller terminal response is missing from local artifacts. Eight stable account reads settled at USD 2.1923892, an observed account-window delta of USD 0.2470144 from the r8 baseline, not complete per-request attribution. No trajectory or ledger row was written, formal completion remains 0/384, and r8 cannot be rerun under its authorization.

Boundary data are built only from the separate 96-run source plan and never from formal result selection. `boundary:run` requires a fresh boundary-scope preflight and writes only below the external artifact root's `boundary/` directory under the USD 102 category. `annotations:extract` reconstructs controller inputs from canonical requests, Session transcripts, and boundary patches while removing reasoning and supervisor decisions. `annotations:prepare` creates a blinded JSONL packet plus an identity-bound CSV. `annotations:freeze` requires two distinct annotators, a distinct adjudicator, complete 180-ID coverage, Cohen's kappa at least 0.75, exactly 60 adjudicated examples per class, and a grouped 54/126 split.

## Integrity and privacy

- Dataset provenance is recorded in `protocol/swe-evo-48.json`.
- Each trajectory must record every ordered worker/controller request, resolved model version, canonical request artifact and SHA-256, model-metadata/preflight hashes, container digest, OpenCode commit, and raw trace SHA-256.
- Model keys must not be copied into task containers, JSONL/CSV, PDFs, LaTeX sources, logs, or archives.
- arXiv upload is outside this artifact and requires separate approval for authors, affiliations, email addresses, ordering, license, and the final PDF.
