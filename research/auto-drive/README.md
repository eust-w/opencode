# AutoDrive Research Artifact

This directory contains the preregistered evaluation and paper artifacts for **AutoDrive: Turn-Boundary Continuation Control for Long-Horizon Coding Agents**.

## Current state

| Artifact | State | Evidence |
| --- | --- | --- |
| System implementation | complete | Core, Protocol, Server, client, app, and browser tests in the repository |
| SWE-EVO manifest | frozen | 48 tasks pinned to upstream commit and Arrow SHA-256 |
| 384-run matrix | frozen | Generated by `@opencode-ai/autodrive-eval` |
| Boundary corpus | pending human work | No labels are fabricated; two independent annotators are required |
| Paid trajectories | pilot gate failed | Two charged preflight attempts are retained under `pilot/`; neither reached a normal boundary or satisfied accepted-result provenance |
| Statistical tables and figures | pending trajectories | Generated only from validated JSONL records |
| Paper numbers | pending trajectories | LaTeX uses explicit `PENDING` markers |

An empty result directory is a legitimate `pending` state, not a successful experiment.

## Layout

- `protocol/`: preregistration, frozen dataset, requests, run matrix, ablations, and fault scenarios.
- `annotations/`: three-state annotation guide and empty import templates.
- `results/`: append-only trajectory index plus derived CSV/JSON/figures after execution.
- `cost/`: append-only cost ledger. It must never exceed the preregistered category or total caps.
- `pilot/`: rejected preflight traces, official baseline grader output, checksums, and the disclosed protocol deviation.
- `paper/`: ACM-style English paper source, bibliography, appendix, and build scripts.
- `reports/`: Chinese research report generated from the same frozen results.

## Commands

Run from `packages/autodrive-eval`:

```bash
bun test
bun typecheck
bun run validate
bun run plan
bun run analyze
```

Paid execution is fail-closed. It requires `run-eval --execute --executor <host-executor>` plus either explicit `--run-id` values or `--all`. The executor runs on the host, receives a per-run maximum cost, and must keep provider credentials outside the task container. Exit code 75 is the only retryable infrastructure failure, and it is retried once.

## Integrity and privacy

- Dataset provenance is recorded in `protocol/swe-evo-48.json`.
- Each trajectory must record the resolved model version, normalized request SHA-256, container digest, OpenCode commit, and raw trace SHA-256.
- Model keys must not be copied into task containers, JSONL/CSV, PDFs, LaTeX sources, logs, or archives.
- arXiv upload is outside this artifact and requires separate approval for authors, affiliations, email addresses, ordering, license, and the final PDF.
